# Design Roadmap

## Objective

Move the portfolio from a collection of polished individual sections into a cohesive product with a stable visual system, stronger storytelling, and clearer conversion paths.

## Current State

- The project already has a recognizable dark-and-neon identity.
- The home page includes strong interactive pieces such as the timeline and skills visualization.
- Several implementation notes exist for specific fixes, but there is no unified plan for system-wide design work.

## Roadmap Principles

- Improve narrative clarity before adding more visual complexity.
- Standardize repeated patterns before designing net-new surfaces.
- Prioritize mobile quality and recruiter readability alongside visual impact.
- Tie design work to measurable portfolio outcomes.

## Phase 1: Foundation

Target: 1 to 2 weeks

- Align typography, spacing, and section rhythm across home, work, services, blog, and contact.
- Normalize button, card, tag, and modal treatments.
- Audit all pages for metadata, OG image coverage, and consistent CTA language.
- Decide on a shared case-study structure for work entries.

Deliverables:

- Finalized design system rules
- Reusable section and card patterns
- Consistent CTA hierarchy

## Phase 2: Narrative and Conversion

Target: 2 to 4 weeks

- Rewrite hero copy around role, differentiation, and strongest proof point.
- Strengthen project summaries with challenge, action, and result framing.
- Improve services and contact pages so they support client inquiries as well as job opportunities.
- Add stronger bridges between resume, work samples, and contact actions.

Deliverables:

- Updated copy deck for all primary pages
- Clear recruiter CTA path
- Clear client CTA path

## Phase 3: Editorial and Trust Signals

Target: 3 to 6 weeks

- Build a consistent visual treatment for blog index and blog detail pages.
- Add trust signals such as testimonials, logos, metrics, certifications, or featured collaborations where available.
- Create reusable templates for article thumbnails, Open Graph images, and resume assets.

Deliverables:

- Blog design pass
- Trust-signal module library
- Asset template library

## Phase 4: Performance and Polish

Target: ongoing

- Audit animation cost on mobile and lower-powered devices.
- Set performance budgets for large motion sections and media assets.
- Tighten accessibility on dialogs, forms, and keyboard navigation.
- Track Lighthouse, Core Web Vitals, and conversion metrics over time.

Deliverables:

- Performance checklist
- Accessibility regression checklist
- Analytics dashboard requirements

## Workstreams

| Workstream | Priority | Why it matters |
| --- | --- | --- |
| Home page narrative | High | First impression and conversion driver |
| Work case studies | High | Strongest proof of capability |
| Services page | Medium | Expands portfolio into lead-generation surface |
| Blog system | Medium | Supports authority and SEO |
| Mobile polish | High | Most likely place for quality gaps in motion-heavy UI |
| Resume and contact funnel | High | Direct path to inquiries |

## Success Metrics

- Faster path from landing to contact action
- Higher quality work-case-study storytelling
- Consistent mobile presentation across major sections
- Lighthouse performance and accessibility scores trending upward
- Cleaner maintenance workflow because shared patterns are documented

## Immediate Next Actions

1. Review the home page against the design system and note inconsistencies.
2. Choose one CTA model to reuse across home, work, services, and contact.
3. Standardize the work-detail content model before adding more projects.
