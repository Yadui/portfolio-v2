## Summary

The site has a functional technical search foundation. Every one of the **28 live
sitemap URLs returned 200** during a sequential Ego Lite browser-fetch audit with
one-second spacing. Every response had a description, canonical, one H1, and
parseable JSON-LD. This is public HTTP/HTML evidence, not confirmation that Google
indexed every page or that AI engines cite it.

The supplied Search Console screenshot shows **2 clicks, 244 impressions, 0.8%
CTR and average position 40.7**, with **3 months / Web / weekly** selected. At this
volume and position, neither a CTR diagnosis nor a ranking forecast is justified.
The strongest visible content leads are passwordless identity/AVD MFA and KV cache.
Obtain a query-by-page export, indexing report and comparable date windows before
attributing low clicks to a particular cause.

## Prioritized follow-up

### P0: security before deployment

- **Rotate/revoke the exposed database token at the provider**, then update the
  approved environment/secret store. Validity was not tested. Review historical
  exposure and provider access logs. Do not paste credentials into issues or chats.
- `npm audit --omit=dev --json` reported **9 affected package entries: 1 critical,
  6 high, 1 moderate, 1 low**. Full install audit reported 21 including development
  dependencies. The critical entry is Next.js; others include Drizzle, Nodemailer,
  sharp, ws, PostCSS, nanoid, baseline-browser-mapping and SimpleWebAuthn. Advisory
  count does not prove exploitability in this deployment. Review current advisories
  and upgrades in a dedicated regression-tested dependency change; do not use
  `npm audit fix --force` blindly. No broad dependency upgrades were made here.

### P1: correct existing articles and preserve URLs

- **AVD:** live copy incorrectly recommends targeting the ARM resource alongside
  the AVD application, and claims blanket Intune/compliance prerequisites for SSO.
  Current Microsoft guidance excludes the AVD ARM Provider from MFA targeting and
  distinguishes product SSO prerequisites from tenant compliance policies. The
  existing illustrative policy also needs API-schema validation. Sources and
  precise review notes are in the content plan.
- **KV cache:** live formula `2 × 32 × 8 × 128 × 8192 × 1 × 2` evaluates to
  **1,073,741,824 bytes = 1 GiB**, not 8.6 GB. Batch 32 with those operands is
  **32 GiB**, not 275 GB. Its attribution to Llama-3 70B also needs correction
  against the checkpoint configuration. The new Qwen draft uses independently
  verified dimensions instead of copying this example.
- Confirm evidence for deployment size, ticket-reduction, quantization-quality and
  latency claims before keeping them. No invented metrics were added to the drafts.
- Replace mechanical title clamping with editorially complete SEO titles. Candidate
  AVD title: **Azure Virtual Desktop: Passwordless MFA with Entra ID**. This is a
  recommendation, not an applied live-title change or ranking guarantee.
- The edit API regenerates slugs from titles. Fix/test slug preservation or provide
  explicit redirects before publishing title revisions. Do not run the editor now
  expecting URLs to remain stable.

### P2: reliability and editorial tooling

- Article DB exceptions currently collapse to not-found when no seeded body exists;
  index/RSS can become empty on failure. Audit error/caching behavior with outage
  tests. The sitemap fallback preserves discovery URLs, not article content.
- The schema uses a fixed millisecond default with a seconds-mode timestamp. Plan
  a reviewed migration; no schema or shared database changes were made here.
- No modified-time column exists; article `dateModified` and sitemap `lastModified`
  reuse creation time. Add authentic modification tracking as a separate change.
- Pipe tables are unsupported without GFM, and the regex TOC can read headings
  inside fenced code. The new drafts avoid tables and fence headings. Fix these
  renderer issues with parser-level tests before depending on them.
- Local uploads are not a shared asset store; pair publication with deployed assets.
  Relative article schema image URLs, preview indexing policy and CRUD validation
  warrant follow-up. No broad authorization/security certification is claimed.
